# Human skull asset

Model and source textures: **Human Skull**, by **CDmir**, published September 23, 2018.

- Source: https://opengameart.org/content/human-skull-0
- Original archive: https://opengameart.org/sites/default/files/skull-obj.zip
- License: **CC0 1.0**, https://creativecommons.org/publicdomain/zero/1.0/
- Original topology: 4,548 triangles in the downloaded OBJ. Created in Blender 2.79.

Local adaptations: geometry centered and uniformly scaled, packed as vertex/index buffers; existing texture maps resized/compressed. The anatomy and UV layout are preserved. See `scripts/prepare-skull.mjs` for the reproducible conversion.

Anatomical photograph consulted as a visual reference (not bundled as artwork): **Humanskull ref front.JPG**, by **Meddlingwithnature**, photographed May 30, 2012, CC BY-SA 3.0: https://commons.wikimedia.org/wiki/File:Humanskull_ref_front.JPG

No AI-generated images, references, textures or geometry were used.
